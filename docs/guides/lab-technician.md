# Lab technician quick guide

## 1. The worklist

Open **Lab**. Orders placed by doctors appear here with their urgency. Filter by status to see what is waiting for a sample.

## 2. Collect a sample

1. Open the order and press **Mark as collected**. The app gives an accession number and a barcode label: print it and stick it on the tube.
2. If the sample is unusable, press **Reject sample** and give the reason. The doctor sees it.

## 3. Enter results

Open the order and type each result. Values outside the normal range are flagged. A **critical** value (far outside) is marked and the doctor must acknowledge it: phone the doctor as well.

## 4. Verify

A second look is the rule. Tick the results that are checked and press **Verify ticked results**. A doctor sees a result only after it is verified.

## 5. Correct a mistake

Verified results are never overwritten. Use the correction action, give a reason and press **Save correction**. The old value stays in the history.

## 6. Outsourced tests

For tests another laboratory does, mark the sample as sent, then enter the result from that laboratory's report when it arrives.

## 7. Print the report

Print the lab report from the order for the patient file.

## Never

Release a result you have not checked, or relabel a tube.
