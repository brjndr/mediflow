# Diagnosis and procedure codes: module notes

What this module is and what was decided for it. The root `CLAUDE.md` holds the rules every module follows, and it wins where the two disagree. Keep this file current with the module.

## What exists

**Diagnosis and procedure codes (web and API):** the ICD-10 and procedure code sets, searched on the server by code (with or without its dot) and by words of the title, a page at a time, and each hospital's favourites among them, which come first in every list and search (#66). Behind the `codes` switch and the `code:read` and `code:manage` permissions. `CodeSearch`, exported from `@/features/codes`, is the search box a clinical screen records a diagnosis or a procedure with: it offers the favourites before anything is typed, asks once for what was typed, works with the keyboard and by touch at any width, and tells the screen which code was chosen. Decided for now: the codes are reference data shared by every hospital and carry no tenant, only the favourite mark is the hospital's own; favourites are the hospital's, not each person's; a code set is never bundled or loaded whole (the mock holds a sample, the API loads the published sets); the search is a `POST` with the term in the body, because it is free text typed while a patient's record may be open and a diagnosis term beside a patient id in an access log is patient data (see Searches under Conventions); a screen that uses `CodeSearch` needs the `codes` switch and `code:read`, and without them the box is disabled and says so. The management screen is desktop-only; the search box is not, and gets its first phone-width use with the clinical screens (M7).

The API (#302) is described in `apps/api/CLAUDE.md`, under Diagnosis and procedure codes. Where it differs from the mock: a word of the title starts where the database says a word starts, which is the same for letters and digits; and whoever marks a favourite needs `code:read` as well as `code:manage`. The full sets are loaded by an operator from a file (`pnpm --filter api codes:load`); the dev seed loads the same sample this mock holds. Which edition of ICD-10 and of the procedure codes the pilot hospital loads is #304.
